# Ripost Messenger Encoder

**Author: https://github.com/shelllab**  

This tool allows you to encode and decode messages for **less secure messaging platforms**.  
⚠️ **Warning: This script does not provide strong security and should not be used for sensitive information.**

---

## Description

The script combines:

1. **Base64 encoding**  
2. **Caesar cipher** with a fixed key

It’s a simple method to “hide” your messages, but **it does not replace proper secure encryption**.

---

## Installation

No external dependencies are required. Just make sure Python is installed.
